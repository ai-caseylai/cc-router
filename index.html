⚡ CC Router Wiki

Welcome to the CC Router Wiki — the complete knowledge base for running Claude Code with multiple LLM backends: DeepSeek V4 Pro DeepSeek Flash MiniMax M3 GLM‑5.1

Claude Code ──▶ cc‑proxy :3456 ──▶ api.minimax.io
├──▶ api.deepseek.com
└──▶ api.z.ai

What is CC Router?

A lightweight Python proxy + CLI toolset that lets Claude Code seamlessly switch between DeepSeek, MiniMax, and GLM models via the built‑in /model picker. One‑command setup, instant switching, no config editing.

🔄 Dynamic Switching

Change models with /model inside Claude Code or cc-model from terminal. No restart needed.

⚡ One‑Click Deploy

python3 setup.py handles everything: proxy, config, auto‑start, verification.

🌐 International Endpoints

Pre‑configured with api.minimax.io, api.z.ai — no 401 traps.

📦 4 LLMs

DeepSeek Pro, Flash, MiniMax M3, GLM‑5.1 — all accessible from one Claude Code instance.

New here? Start with Quick Start or jump to Installation.

📦 Installation

Home / Installation

Prerequisites

  • macOS 12+ (Linux/Windows: manual steps)
  • Python 3 (built‑in)
  • Claude Code (auto‑installed if missing)

Automatic (macOS)

python3 setup.py

Manual Deployment

Step 1: Create cc‑proxy

mkdir -p ~/Documents/minimax

Copy cc-proxy.py from the repo, fill in your API keys.

Step 2: Configure settings.json

{
  "env": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:3456",
    "ANTHROPIC_AUTH_TOKEN": "dummy",
    "ANTHROPIC_MODEL": "deepseek-v4-pro[1m]",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "MiniMax-M3",
    "API_TIMEOUT_MS": "3000000",
    "CLAUDE_CODE_AUTO_COMPACT_WINDOW": "512000",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  }
}

Step 3: Start proxy

python3 ~/Documents/minimax/cc-proxy.py &

Step 4: Add cc‑model alias

echo "alias cc-model='bash ~/Documents/minimax/cc-model.sh'" >> ~/.zshrc

Step 5: macOS auto‑start (optional)

Create ~/Library/LaunchAgents/com.cc-proxy.plist — see launchd guide.

Verify Installation

curl http://127.0.0.1:3456/health     # → {"status":"ok"}
curl http://127.0.0.1:3456/v1/models  # → list of 3-4 models
claude                                 # /status → http://127.0.0.1:3456

MiniMax M3 ⚠️ tricky

Home / Providers / MiniMax M3

Overview

MiniMax M3 is a strong coding model with extended thinking support. Critical: it requires the international endpoint.

ModelIDKey Prefix
MiniMax M3MiniMax-M3sk-cp-
Biggest trap: Their docs show the CN endpoint api.minimaxi.com which returns 401 invalid api key for non‑CN users. Always use api.minimax.io.

Correct Endpoint

https://api.minimax.io/anthropic/v1/messages   ← ✅ International
https://api.minimaxi.com/anthropic/v1/messages  ← ❌ CN only → 401

API Key

  1. Register at platform.minimaxi.com
  2. Create API key → format: sk-cp-xxxxxxxx
  3. Auth header: x-api-key (Claude Code sends as ANTHROPIC_AUTH_TOKEN)

Test Connectivity

curl -s https://api.minimax.io/anthropic/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: sk-cp-YOUR_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{"model":"MiniMax-M3","max_tokens":5,"messages":[{"role":"user","content":"hi"}]}'

# Expected: {"type":"message","role":"assistant","model":"MiniMax-M3",...}

Features

  • Extended Thinking (default ON in Claude Code — toggle with Option+T / Alt+T)
  • Context window: 512K → set CLAUDE_CODE_AUTO_COMPACT_WINDOW: "512000"

🕹️ Model Switching

Home / Usage / Switching

Two Ways to Switch

Terminal: cc-model

Changes the Default + Haiku mapping. Best for setting up your preferred model pair.

cc-model pro      # DeepSeek Pro + MiniMax
cc-model flash    # DeepSeek Flash + MiniMax
cc-model minimax  # MiniMax + DeepSeek Pro
cc-model glm      # GLM‑5.1 + MiniMax

Claude Code: /model

Instant toggle between the two slots. No restart.

/model → arrow keys
Default ↔ Haiku
Why only 2 slots? Claude Code's /model picker shows Default + Haiku for non‑Anthropic providers. Use cc-model to rotate the 3rd/4th models into these slots.

Typical Workflow

  1. Start with cc-model pro (DeepSeek Pro default)
  2. Open Claude Code, type /model → see Default=DeepSeek Pro, Haiku=MiniMax
  3. Toggle with arrow keys as needed
  4. Need Flash? cc-model flash in terminal, then /model again

🔧 Architecture

Home / Internals / Architecture
┌─────────────────────────────────────────────┐
│ Claude Code │
│ Reads ~/.claude/settings.json │
│ Sends POST /v1/messages?beta=true │
└──────────────────┬──────────────────────────┘
│ http://127.0.0.1:3456
▼
┌─────────────────────────────────────────────┐
│ cc-proxy.py :3456 │
│ Parse model field → route to provider │
│ Handle SSE streaming │
│ Strip ?beta=true query param │
└────┬──────────────┬──────────────┬───────────┘
│ │ │
▼ ▼ ▼
api.deepseek api.minimax api.z.ai
DeepSeek Pro MiniMax M3 GLM‑5.1
DeepSeek Flash

Request Flow

  1. Claude Code reads settings.json → ANTHROPIC_BASE_URL = http://127.0.0.1:3456
  2. User sends a message → Claude Code POSTs to proxy with model field from settings
  3. Proxy parses model, looks up in PROVIDERS dict
  4. Proxy forwards request to matching upstream API with the provider's real key
  5. Response streamed back to Claude Code

Design Decisions

  • No API keys in settings.json — proxy holds all keys internally
  • Python stdlib only — zero dependencies, works on any macOS
  • Single‑process — one HTTPServer, simple to debug
  • Model‑based routing — the model field in the request body drives provider selection

Streaming Support

Home / Internals / Streaming

How It Works

Claude Code sends {"stream": true} in requests. The proxy forwards this flag to the upstream API and then streams the response chunk‑by‑chunk:

def stream_response(resp, wfile):
    while True:
        chunk = resp.read(4096)
        if not chunk: break
        wfile.write(chunk)
        wfile.flush()

?beta=true Query Param

Claude Code v2.1.x appends ?beta=true to /v1/messages. Early proxy versions did exact path matching and returned 404. Current version strips query params:

path = self.path.split("?")[0]   # "/v1/messages?beta=true" → "/v1/messages"

Headers Passed Through

  • Content-Type
  • x-api-key (or Authorization)
  • anthropic-version
  • Accept
  • All upstream response headers (except Transfer‑Encoding, Connection, Keep‑Alive)

"model may not exist" Error

Home / Troubleshooting / model may not exist

Symptoms

⏺ There's an issue with the selected model (deepseek-v4-flash).
   It may not exist or you may not have access to it.

Root Causes

  1. Proxy not running — most common
  2. Proxy path matching bug — ?beta=true rejected (fixed in current version)
  3. /v1/models endpoint missing — Claude Code validates models before sending

Fix

# 1. Check if proxy is running
curl http://127.0.0.1:3456/health
# Expected: {"status":"ok"}

# 2. Check if /v1/models responds
curl http://127.0.0.1:3456/v1/models
# Expected: {"object":"list","data":[...]}

# 3. Restart proxy if needed
lsof -ti :3456 | xargs kill
python3 ~/Documents/minimax/cc-proxy.py &

# 4. Verify the model works directly
curl -s http://127.0.0.1:3456/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: x" \
  -d '{"model":"MiniMax-M3","max_tokens":5,"messages":[{"role":"user","content":"hi"}]}'

API Timeout · Retrying

Home / Troubleshooting / Timeout

Symptoms

Retrying in 0s · attempt 4/10 · API_TIMEOUT_MS=3000000ms, try increasing it

Causes

  1. Wrong ANTHROPIC_BASE_URL — pointing to a dead or wrong endpoint
  2. Proxy not running — port 3456 has no listener
  3. Port mismatch — settings.json has 3457 but proxy is on 3456
  4. Env var override — ~/.zshrc exports overriding settings.json

Fix

# Check current endpoint
grep ANTHROPIC_BASE_URL ~/.claude/settings.json
# Should be: "ANTHROPIC_BASE_URL": "http://127.0.0.1:3456"

# Check for env var overrides
grep ANTHROPIC ~/.zshrc
# If any uncommented export lines exist → comment them out

# Check proxy is running on correct port
lsof -i :3456
# Should show python3 listening

# In Claude Code
/status   # Verify ANTHROPIC_BASE_URL

Environment Variable Conflicts

Home / Troubleshooting / Env Var Conflicts

Priority Order

🥇 ~/.zshrc export ANTHROPIC_*      ← HIGHEST
🥈 ~/.claude/settings.json env
🥉 ~/.claude.json

Common Scenario

You have both:

# In ~/.zshrc
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"

# In ~/.claude/settings.json
"ANTHROPIC_BASE_URL": "http://127.0.0.1:3456"

→ Result: Claude Code uses api.deepseek.com directly, bypassing the proxy entirely.

Fix

# Comment out ALL ANTHROPIC_* lines in ~/.zshrc
sed -i '' 's/^export ANTHROPIC_/# export ANTHROPIC_/' ~/.zshrc

# Open a new terminal (or source ~/.zshrc) for changes to take effect

Also Check

Some tools auto‑inject env vars:

  • ccr activate (claude-code-router) — may set ANTHROPIC_BASE_URL
  • SkillHub CLI — may inject DeepSeek env vars
  • WorkBuddy — may inject its own ANTHROPIC config

Check the bottom of ~/.zshrc for auto‑injected blocks.

launchd "Operation not permitted"

Home / Troubleshooting / launchd

Symptoms

/Applications/Xcode.app/Contents/Developer/usr/bin/python3:
can't open file '/Users/perry/Documents/minimax/cc-proxy.py':
[Errno 1] Operation not permitted

Cause

macOS privacy restriction. The Python binary used by launchd doesn't have Full Disk Access to read files in ~/Documents/.

Fix (Option 1 — Recommended)

Move cc-proxy.py to a system‑accessible location and update the plist:

sudo cp ~/Documents/minimax/cc-proxy.py /usr/local/bin/cc-proxy.py
sudo chmod +x /usr/local/bin/cc-proxy.py

Then update the plist ProgramArguments to point to /usr/local/bin/cc-proxy.py.

Fix (Option 2)

Grant Full Disk Access to Python: System Settings → Privacy & Security → Full Disk Access → add /usr/bin/python3.

Fix (Option 3 — Use Homebrew Python)

brew install python@3.12
# Use /opt/homebrew/bin/python3 in the plist
