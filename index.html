One‑command Claude Code multi‑model router — DeepSeek Pro / Flash + MiniMax M3 + GLM‑5.1, switch from /model

📐 Architecture

Claude Code ──▶ cc‑proxy :3456 ──▶ api.minimax.io
├──▶ api.deepseek.com
└──▶ api.z.ai

A lightweight Python proxy (cc‑proxy.py) sits between Claude Code and multiple LLM APIs. It parses the model field from each request and routes it to the matching provider — instant, zero-config switching.

Claude Code's /model picker shows 2 slots (Default + Haiku). Use the cc‑model CLI to rotate which models fill those slots.

🔑 API Keys — Deep Dive

DeepSeek

Register at platform.deepseek.com, top up, create an API key. One key serves both deepseek-v4-pro[1m] and deepseek-v4-flash.

Anthropic‑compatible endpoint: https://api.deepseek.com/anthropic/v1/messages

MiniMax

Register at platform.minimaxi.com. Keys start with sk-cp-.

Must use api.minimax.io (international). api.minimaxi.com returns 401 invalid api key.

GLM‑5.1 (Zhipu AI)

Register at open.bigmodel.cn. Key format: xxx.yyy.zzz.

International endpoint: https://api.z.ai/api/anthropic/v1/messages

Key Storage

API keys are stored in ~/Documents/minimax/cc‑proxy.py (the generated router script). They are not in settings.json — the proxy handles all authentication internally.

ANTHROPIC_AUTH_TOKEN in settings.json can be any dummy string.

How Claude Code Connects

"ANTHROPIC_BASE_URL": "http://127.0.0.1:3456"   ← points to local proxy
  "ANTHROPIC_AUTH_TOKEN": "dummy"                ← proxy handles real auth

The proxy strips ?beta=true query params and forwards to the correct upstream based on the model field in the request body.

🕹️ Usage

Terminal Switching

cc-model pro        # Default=DeepSeek V4 Pro  → Haiku=MiniMax M3
cc-model flash      # Default=DeepSeek Flash   → Haiku=MiniMax M3
cc-model minimax    # Default=MiniMax M3       → Haiku=DeepSeek Pro
cc-model glm        # Default=GLM‑5.1          → Haiku=MiniMax M3
cc-model status     # Show current mapping + proxy health

Inside Claude Code

Type /model in the TUI. Arrow‑key between Default ↔ Haiku to switch instantly. No restart needed.

The cc-model Alias

Added to ~/.zshrc during setup:

alias cc-model='bash ~/Documents/minimax/cc-model.sh'

Verification

# Proxy health
curl http://127.0.0.1:3456/health      # → {"status":"ok"}

# Model list
curl http://127.0.0.1:3456/v1/models   # → MiniMax-M3, deepseek-v4-pro[1m], ...

# In Claude Code
/status   # ANTHROPIC_BASE_URL → http://127.0.0.1:3456
/model    # Shows current mapping

🩺 Troubleshooting

❌ "model may not exist"

Cause: Proxy is not running (or the ?beta=true query param was rejected by early proxy versions).

# Check
curl http://127.0.0.1:3456/health

# Restart
lsof -ti :3456 | xargs kill
python3 ~/Documents/minimax/cc-proxy.py &

❌ MiniMax 401 · invalid api key

Three possible causes:

  1. Using api.minimaxi.com instead of api.minimax.io
  2. API key expired on MiniMax platform
  3. Key truncated or malformed (starts with sk-cp-)

Test directly:

curl -s https://api.minimax.io/anthropic/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: sk-cp-YOUR_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{"model":"MiniMax-M3","max_tokens":5,"messages":[{"role":"user","content":"hi"}]}'

❌ API Timeout · Retrying

Cause: ANTHROPIC_BASE_URL pointing to a dead endpoint. Common when:

  • ~/.zshrc has export ANTHROPIC_BASE_URL=... overriding settings.json
  • Proxy not running on port 3456
  • Port mismatch (settings.json has 3457 but proxy is on 3456)
# Check for env var conflicts
grep ANTHROPIC ~/.zshrc

# Comment them out
sed -i '' 's/^export ANTHROPIC_/# export ANTHROPIC_/' ~/.zshrc

❌ launchd "Operation not permitted"

macOS privacy restriction. Fix: System Settings → Privacy & Security → Full Disk Access → add /usr/bin/python3.

Or use /usr/local/bin/python3 in the plist instead.

❌ Config conflict: env vars vs settings.json

Priority order:

1. ~/.zshrc export ANTHROPIC_*    ← HIGHEST (overrides everything)
2. ~/.claude/settings.json env    ← MIDDLE
3. ~/.claude.json                 ← LOWEST

If you set ANTHROPIC_BASE_URL in both .zshrc and settings.json, the .zshrc value wins.

Why Only 2 Slots in /model?

Claude Code's /model picker shows Default (ANTHROPIC_MODEL) + Haiku (ANTHROPIC_DEFAULT_HAIKU_MODEL) + the current custom model. Opus and Sonnet aliases exist but are not rendered in the non‑Anthropic provider UI.

The cc-model script rotates the third/fourth models into these two visible slots as needed.

Streaming Support

The proxy handles SSE streaming natively — reads chunks from the upstream response and forwards them immediately. Claude Code's ?beta=true query parameter is stripped before path matching.

macOS Auto‑Start

A launchd plist at ~/Library/LaunchAgents/com.cc-proxy.plist ensures the proxy survives reboots. Loaded with launchctl load, kept alive with KeepAlive.
